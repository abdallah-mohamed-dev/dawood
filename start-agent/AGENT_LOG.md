# سجل عمل الـAgents — Append-Only

هذا الملف **بيتكتب فيه فقط ولا يُعدَّل فيه** (append-only). كل Agent/موديل بيشتغل على المشروع لازم:

1. **يضيف إدخال "بداية جلسة"** فور ما يبدأ الشغل (حتى قبل أي كود) — عشان لو حصل انقطاع، الإدخال يوضح إنه كان شغال وعلى إيه.
2. **يضيف إدخال "نهاية جلسة/تاسك"** فور ما يخلّص أي تاسك أو جزء منه — حتى لو التاسك مش خلصان بالكامل.
3. **ميحذفش ولا يعدّل** أي إدخال قديم — بس يضيف إدخال جديد في آخر الملف.

## الصيغة (انسخها والصقها في آخر الملف، واملأها)

```markdown

**التاسك:** [رقم ووصف التاسك من docs/tasks.md — مثال: "Task 9 — الشركاء والسحوبات"]

**اللي اتعمل:**
- [نقطة 1]
- [نقطة 2]

**حالة الاختبارات:** [عدد الاختبارات قبل] → [عدد الاختبارات بعد] (كلها ناجحة / فيه فشل: اذكره)

**بنود docs/tasks-checklist.md اتعلّمت:** [اذكر البنود أو "لا يوجد بعد"]

**ملاحظات لأي Agent جاي:** [أي حاجة محتاج الشخص اللي بعدك ياخد باله منها — قرار اتاخد، مشكلة واجهتك، حاجة لسه ناقصة]
---
```

## 1. المطلوب (بكلام المستخدم)

> عندنا تاسك مهم وهوا خاص باننا محتاجين صفحة للباكبس ويكون فيها باكب للسيستم بالكامل... ويكون فى امكانيه لعمل باكب للداتابيز كلها وتنزيلها كملف بحيث يكون فى باكب دورى نعمله بشكل يدوى حاليا

هذا التاسك يغطي الجزء الأول بس: صفحة الباكب + تحميل نسخة كاملة من قاعدة البيانات كملف واحد.

## 2. السياق والأسئلة المحسومة

**ليه محتاجين ده؟** حاليًا مفيش أي وسيلة لأخذ نسخة احتياطية من بيانات النظام غير الدخول للسيرفر يدويًا. المستخدم عايز زرار في الواجهة.

راجع `specs/TASKS.md` — الدفعة الثالثة (تاسكات 10→14) — لكل القرارات المعمارية المعتمدة مسبقًا لهذه الدفعة كاملة. الأهم هنا:
- القاعدة SQLite → الباكب = نسخ ملف `database/database.sqlite` نفسه، مفيش تصدير/استيراد بيانات.
- صفحة واحدة `GET /backup` تجمع كل أزرار الباكب المستقبلية (هذا التاسك يضيف زرار واحد بس).
- باكب يدوي فقط، بدون تخزين نسخ على السيرفر.

**خارج النطاق صراحة:** أي تصدير CSV (تاسكات 11-14)، أي جدولة تلقائية، أي حفظ سجل للنسخ اللي اتاخدت.

## 3. الخطة التفصيلية

### 3.1 قاعدة البيانات
لا تغيير.

### 3.2 المنطق (Controllers)
`app/Http/Controllers/BackupController.php`:
- `index(): View` — يعرض صفحة الباكب (حاليًا فيها كارت واحد بس).
- `downloadDatabase(): StreamedResponse` — `response()->download(database_path('database.sqlite'), 'dawood-backup-'.now()->format('Y-m-d-His').'.sqlite')`.

### 3.3 التحقق (Form Requests)
لا يوجد — الزرار GET بسيط بدون مدخلات.

### 3.4 الواجهة (Controllers / Routes / Views)
- `routes/web.php`: جوه `middleware('auth')` —
  `Route::get('/backup', [BackupController::class, 'index'])->name('backup.index');`
  `Route::get('/backup/database', [BackupController::class, 'downloadDatabase'])->name('backup.database');`
- `resources/views/backup/index.blade.php` — صفحة بسيطة بكارت "نسخة كاملة من قاعدة البيانات" + وصف مختصر + رابط تحميل (`<a href="{{ route('backup.database') }}">`) بنفس أسلوب الأزرار الأساسية الموجودة في الصفحات التانية.
- `resources/views/components/app-layout.blade.php` — إضافة عنصر `['route' => 'backup.index', 'active' => 'backup.*', 'label' => 'النسخ الاحتياطي']` آخر القائمة.

### 3.5 الاختبارات
`tests/Feature/BackupTest.php`:
- زائر غير مسجل يتحول لصفحة الدخول عند `/backup` وعند `/backup/database`.
- مستخدم مسجل: `/backup` بيرجع 200 وفيه رابط التحميل.
- مستخدم مسجل: `/backup/database` بيرجع استجابة تحميل (header `Content-Disposition` فيه `attachment`) وبامتداد `.sqlite`.

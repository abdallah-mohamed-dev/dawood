## 2. السياق والأسئلة المحسومة

**ليه محتاجين ده؟**
التصدير الموجود دلوقتي (`backup.csv`) بيطلع **zip فيه كل الجداول بشكلها الخام**: أسماء أعمدة إنجليزية، ومبالغ بالقروش (`8500000` بدل `85,000.00`)، و`customer_id` بدل اسم العميل. ده نسخة احتياطية، **مش** ملف يتفتح على Excel ويتقري. المطلوب ملفات منفصلة مقروءة بالعربي.

**أسئلة اتحسمت قبل التنفيذ:**

| السؤال | الإجابة المعتمدة | مين حسمها |
|---|---|---|
| "المشتريات" في التاسك 13 — إيه هي بعد إلغاء الدفعات (spec 014)؟ | **حركات المخزون من نوع شراء** (`InventoryMovement` بـ`type = purchase`). جدول `inventory_batches` اتشال في 014، فمفيش كيان "عملية شراء" مستقل تاني | ✅ محسوم في spec 014 |
| التصدير بيتفلتر بالموسم؟ | **لأ — تصدير كامل لكل البيانات.** الغرض أرشيف يتفتح على Excel. الفلترة بالموسم موجودة في الصفحات نفسها | ⚠️ افتراض — لو المستخدم عايز فلتر موسم، يتعمل بند إضافي |
| الملفات تنزل منفصلة ولا zip؟ | **كل ملف لوحده** بزرار مستقل. الـzip الشامل موجود بالفعل في `backup.csv` ومش بيتلمس | ✅ من نص التاسك ("منفصل") |
| المبالغ تتصدّر بالقروش ولا بالجنيه؟ | **بالجنيه بصيغة عشرية** (`85000.00`) عن طريق `MoneyCast::toDecimalString()`. الكميات بـ`QuantityCast::toDecimalString()` (3 خانات) | ✅ قاعدة المشروع: التحويل عبر الـCasts حصرًا |
| فاصل الأعمدة والترميز؟ | **فاصلة `,` + UTF-8 BOM** في أول كل ملف. من غير BOM، Excel على ويندوز يقرا العربي حروف مكركبة | ⚠️ قرار تقني — الـzip الحالي مفيهوش BOM، وده سبب إن ملفاته بتطلع مكركبة |

## 3. الخطة التفصيلية

### 3.1 قاعدة البيانات

### 3.2 المنطق (Services / Models / Enums)

**مفيش Service جديد.** التصدير تجميع قراءة بحت، ومكانه الكونترولر.

**ملف واحد جديد:** `app/Http/Controllers/Exports/CsvExportController.php`

فيه **دالة مساعدة private واحدة** بتتكرر 9 مرات (ده مش تجريد مبكر — 9 استخدامات فعلية):

```php
/**
 * @param  list<string>  $headers  عناوين الأعمدة بالعربي
 * @param  iterable<array<int, string|null>>  $rows
 */
private function stream(string $filename, array $headers, iterable $rows): StreamedResponse
{
    return response()->streamDownload(function () use ($headers, $rows) {
        $handle = fopen('php://output', 'w');
        fwrite($handle, "\xEF\xBB\xBF");   // BOM — بدونه Excel بيكركب العربي
        fputcsv($handle, $headers);
        foreach ($rows as $row) {
            fputcsv($handle, $row);
        }
        fclose($handle);
    }, $filename, ['Content-Type' => 'text/csv; charset=UTF-8']);
}
```

**قواعد إلزامية على كل دالة تصدير:**
1. **ممنوع `float`.** كل مبلغ بييجي من `$model->getRawOriginal('column')` (integer بالقروش) ويتحول نص بـ`MoneyCast::toDecimalString()`. وكل كمية بـ`QuantityCast::toDecimalString()`.
2. **ممنوع حساب جديد.** أي رقم مشتق (ربح، متبقي، قيمة مخزون) بييجي من **الدالة الموجودة** في الموديل أو الـService (`$room->paidAmount()`, `$room->remainingAmount()`, `InventoryService::stockValue()`...). لو الرقم مش موجود كدالة، **صدّر الأعمدة الخام وسيب الحساب لـExcel** — متكتبش صيغة جديدة.
3. **`->cursor()` مش `->get()`** على كل استعلام، مع `with()` للعلاقات اللي بتتعرض — عشان مفيش N+1 ولا استهلاك رام.
4. اسم الملف: `dawood-<اسم>-<Y-m-d>.csv` (مثال: `dawood-customers-2026-10-06.csv`).
5. التواريخ بصيغة `Y-m-d` (نفس صيغة كل الجداول في النظام).
6. القيم الفاضية = نص فاضي `''`، مش `null` ومش `—`.

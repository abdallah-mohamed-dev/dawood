## 🔴 التحذير الأهم في الملف ده

**ممنوع تبدأ الدفعة دي قبل ما التصفية (`specs/012`) تخلص.**

كل تقرير وكل فلتر في الملف ده محتاج يعرف **الموسم**. لو اتكتبوا قبل المواسم، كل واحد فيهم هيجمع بيانات **عابرة للمواسم** — يعني رقم بيخلط موسم اتصفّى واتوزعت أرباحه مع موسم شغال. الرقم ده مالوش أي معنى محاسبي، والشغل كله هيتكتب تاني.

**لو لقيت `specs/012` لسه مش مكتمل — قف وقول للمستخدم.**

5. بعد كل تاسك: `php artisan test --compact` + `vendor/bin/pint --dirty --format agent` + `npm run build`.

# التاسك 19.3 — الفلاتر والبحث في باقي الصفحات

**القايمة دي معتمدة من المستخدم حرفيًا.** الصفحات اللي **مش** في القايمة بياناتها قليلة بطبيعتها ومش محتاجة — **متضيفلهاش فلاتر.**

| الصفحة | المطلوب | الحالة |
|---|---|---|
| **العملاء** | بحث بالاسم والتليفون | 🆕 |
| **المدفوعات** | بحث بالعميل والغرفة و**رقم الإيصال** + فلتر تاريخ + فواصل شهور | 🆕 |
| **المصروفات** | بحث + فلتر البند + فلتر تاريخ | جزئي — فواصل الشهور موجودة |
| **الخزنة** | فلتر نوع الحركة + تاريخ + طريقة الدفع | جزئي — فواصل الشهور اتعملت في `specs/013` |
| **رأس المال** | بحث + فلتر تاريخ | ✅ اتعمل في `specs/015` — **تأكد بس** |
| **صفحة الشريك** | فلتر تاريخ على السحوبات | 🆕 |
| **تقرير الربح** | فلتر فترة وموسم | 🆕 |

- [ ] **19.3.1** **العملاء** — بحث في `name` و`phone`، `withQueryString()` مع الباجينيشن
- [ ] **19.3.2** **المدفوعات** — بحث في اسم العميل ونوع الغرفة ورقم الإيصال + فلتر `from`/`to` على `paid_at` + فواصل شهور بالإجماليات
  ⚠️ البحث برقم الإيصال: العمود **integer**. اقبل من المستخدم `00012` أو `12` — نظّف الأصفار من الشمال قبل المقارنة.
- [ ] **19.3.3** **المصروفات** — بحث في `description` + فلتر `expense_category_id` + `from`/`to`. **الإجماليات الشهرية الموجودة لازم تعكس الفلتر**
- [ ] **19.3.4** **الخزنة** — فلتر `kind` + `payment_method` + `from`/`to`، على الجدولين. **الكروت العلوية (الرصيد والإجماليات) تفضل للكل مش للمفلتر**، وتحتها سطر صغير بيقول كده
- [ ] **19.3.5** **صفحة الشريك** — فلتر `from`/`to` على السحوبات. **كروت النصيب والمستحق تفضل للكل**
- [ ] **19.3.6** **تقرير الربح** — فلتر الموسم (الافتراضي المفتوح). موسم مقفول → **الأرقام من السنابشوت المخزّن** (ق-7 في `specs/012`)، **ممنوع إعادة حساب**
- [ ] **19.3.7** كل فلتر: زرار "إلغاء الفلاتر" + `withQueryString()` + رسالة فاضية مناسبة بالعربي
- [ ] **19.3.8** **ممنوع** تضيف فلاتر لـ: صفحة العميل الواحد · بنود المصروفات · الشركاء · المواسم · النسخ الاحتياطي · الإعدادات · البروفايل

### 3.2 المنطق (Services / Models / Enums)

**إضافة واحدة بس** — `app/Services/CashboxService.php`:

```php
/**
 * سلسلة شهرية للخزنة — قراءة فقط، للعرض.
 *
 * @return list<array{month: string, label: string, in: int, out: int, balance_end: int}>
 */
public function monthlySeries(int $months = 6): array
```

**السلوك المطلوب بالحرف:**
1. نافذة آخر `$months` شهر **منتهية بالشهر الحالي** (لو الشهر الحالي ما فيهوش حركات، يظهر بأصفار ورصيد مرحّل).
2. استعلام تجميعي **واحد** على `cashbox_transactions`: `GROUP BY` على سنة+شهر `occurred_at`، مع `SUM(CASE WHEN type = 'in' THEN amount ELSE 0 END)` و`SUM(CASE WHEN type = 'out' ...)`.
3. `balance_end` لكل شهر = **الرصيد قبل بداية النافذة** (استعلام واحد إضافي: مجموع الداخل ناقص الخارج لكل حركة قبل أول يوم في النافذة) **+** مجموع صوافي الشهور لحد الشهر ده.
   ⚠️ **مش** مجموع شهور النافذة لوحدها — كده الرصيد هيطلع غلط لأن النظام فيه رصيد افتتاحي وحركات أقدم.
4. كل القيم **integer بالقروش**. ممنوع `float` في الدالة. القسمة الوحيدة المسموحة هي في العرض.
5. `label` = اسم الشهر بالعربي من `lang/ar` (نفس مصدر فواصل شهور المصروفات — **متكتبهوش hardcoded**).
6. مفيش `DB::transaction` ومفيش `lockForUpdate` — قراءة بحتة.
7. مفيش فلتر موسم. الخزنة نقدية وعابرة للمواسم بطبيعتها (قاعدة المشروع رقم 6).

**ممنوع أي إضافة تانية في الـServices.** الرسومات الباقية بتقرا من الموجود:

| الرسمة | مصدر البيانات (موجود بالفعل) |
|---|---|
| شلال الربح | `ProfitService`: `revenue()`, `costOfMaterials()`, `roomCosts()`, `cancelledRoomCosts()`, `adminExpenses()`, `netProfit()` |
| أصول مش تكلفة | `ProfitService::workInProgress()`, `stockValue()` |
| تركيب سعر البيع للغرفة | `ProfitService::forRoom($room)` |
| نصيب الشركاء | `PartnerService` (الموجود) |
| التفصيل الشهري | `ProfitService::adminExpensesByMonth()`, `laborCostsByMonth()`, `otherRoomCostsByMonth()` |
| داخل/خارج حسب النوع | `CashboxService::summary()`, `breakdownByMethod()` |

6 مكونات. **كلها تستقبل أرقام integer بالقروش وتحوّل للعرض جواها.**

| `sparkline` | `:values` `token` | جوه كروت الـKPI |

**قواعد إلزامية لكل مكون رسمة:**
1. **الألوان من الـclasses بس** (`fill-chart-a`, `stroke-chart-grid`, `fill-ramp-1`...). **ممنوع hex، وممنوع `style="fill:#..."`**.
2. **محور القيم على اليمين** والزمن ماشي **من اليمين للشمال** (RTL). الأقدم يمين، الأحدث شمال.
3. **زرار "جدول"** في كل رسمة يقلبها جدول بنفس الأرقام (Alpine: `x-data="{ view: 'chart' }"`). ده **شرط إمكانية وصول، مش اختياري** — ومعناه إن الرقم موجود كنص في الصفحة حتى لو الرسمة ما ظهرتش.
4. **`alt` إلزامي** على كل `<svg>` (`role="img"` + `aria-label`) وفيه رقم حقيقي، مش وصف عام.
5. tooltip على كل عنصر (Alpine)، ومسموح يكون بسيط.
6. أطراف الأعمدة مدوّرة 4px من ناحية البيانات بس، وفاصل 2px بين أي فيلين ملتزقين.
7. **الحسابات الهندسية (بكسلات) float عادي ومسموح** — ده عرض، مش منطق أعمال. **القيم المالية نفسها تفضل integer** وتتحول نص بـ`MoneyCast::toDisplayString()`. ⚠️ القاعدة رقم 1 في `CLAUDE.md` بتتكلم عن طبقة الأعمال، والرسم مش طبقة أعمال — البند ده مكتوب هنا صراحة عشان المراجعة ما تعتبرهوش مخالفة.
8. أي رسمة بدون بيانات (كل القيم صفر) تعرض **حالة فاضية بنص عربي**، مش رسمة فاضية.

1. **لو أي حاجة مش واضحة — قف واسأل المستخدم.**
2. **`specs/016` لازم يكون خلص.** التاسك ده بيضيف بوكس جديد لصفحة الغرفة المقسّمة. لو الصفحة لسه 254 سطر، ارجع لـ016.
3. **التسعير تقديري بحت.** **ممنوع** يدخل في `ProfitService` أو `CashboxService` أو أي حساب ربح حقيقي. هو رقم بيكتبه المستخدم عشان يقارن بيه بعدين وخلاص.

## القواعد الحاكمة (قرارات معتمدة من المستخدم)

1. **التسعير يتعدّل بحرية طول ما الغرفة مش "مكتملة". أول ما تكتمل يتقفل.**
   السبب: لو اتعدّل بعد الاكتمال، المقارنة بين التقدير والفعلي هتتغير بأثر رجعي وما تبقاش بتعبّر عن حاجة.
2. **مدة التنفيذ بتبدأ من أول ما الغرفة تبقى "تحت التنفيذ"** — مش من يوم التسعير ومش من يوم الإنشاء.
3. **لو الغرفة رجعت من مكتملة لتحت التنفيذ واكتملت تاني:** تاريخ البداية يفضل **أول مرة** دخلت فيها تحت التنفيذ (ما بيتكتبش فوقه)، وتاريخ النهاية بياخد **آخر** اكتمال.
4. **سجل تعديلات الغرفة متعملش من أول** — سجل العمليات العام من `specs/013` بيلتقطه كله تلقائي. المطلوب هنا **عرض مفلتر** بس.

# التاسك 17.4 — حساب الفعلي والمقارنة

- [ ] **17.4.1** `app/Models/Room.php` — فصل تكلفة الخامات عن الاكسسوارات:
  ```php
  public function materialsCostByType(): array  // [material_type_id => cost]
  ```
  بتعدّي على `roomMaterials` (المحمّلة) وبتجمّع `cost` الخام حسب `material.material_type_id`.
  **ممنوع استعلام جوه loop** — لو العلاقة مش محمّلة، حمّلها مرة واحدة.
- [ ] **17.4.2** `ProfitService::forRoom()` — **متغيّرش توقيعها ولا مفاتيحها الحالية** (حاجات تانية بتعتمد عليها). ضيف دالة جديدة:
  ```php
  public function pricingComparison(Room $room): array
  ```
  بترجّع لكل بند من الأربعة: `['estimated' => ?int, 'actual' => int, 'difference' => ?int]`
  - **خامات** ← تكلفة المواد من نوع "خامة"
  - **اكسسوار** ← تكلفة المواد من نوع "اكسسوار"
  - **مصنعية** ← `laborCost()`
  - **مصروفات أخرى** ← `otherCost()`
  - \+ صف **الإجمالي**
  - `difference = actual − estimated` (موجب = التكلفة زادت عن التقدير). لو التقدير `null` → `difference = null`
  - ⚠️ **بتقرا من `materialsCostByType()` بأرقام خام — بلا أي `float`.**
- [ ] **17.4.3** `pricingComparison()` **تجميع بحت، ما بتكتبش أي حاجة في أي جدول** — زي باقي `ProfitService`
- [ ] **17.4.4** مقارنة المدة:
  ```php
  public function durationComparison(Room $room): array
  // ['expected' => ?int, 'actual' => ?int, 'difference' => ?int]
  ```
  - `actual` = عدد الأيام من `started_at` لـ`completed_at` (شامل الطرفين). `null` لو أي واحد منهم فاضي
  - `difference = actual − expected` (موجب = اتأخرنا)

## ⚠️ اقرا ده الأول — تعليمات للموديل المنفّذ

**الملف ده مكتوب عشان تنفّذه من غير ما تاخد أي قرار بنفسك.** كل قرار اتاخد خلاص واتكتب هنا.

1. **لو لقيت حاجة مش واضحة أو ناقصة — قف واسأل المستخدم. متجتهدش ومتخمّنش.**
2. **اقرا `CLAUDE.md` و`start-agent/PITFALLS.md` قبل أي كود.** القواعد اللي فيهم فوق أي حاجة هنا.
3. **نفّذ تاسك تاسك بالترتيب.** متبدأش تاسك قبل ما اللي قبله يخلص ويعدّي اختباراته.
4. **بعد كل تاسك:** `php artisan test --compact` (كل الاختبارات، القديمة والجديدة) ثم `vendor/bin/pint --dirty --format agent`، وبعدين علّم ✔ في checklist التاسك.
5. **لو فيه تغيير واجهة:** `npm run build`.
6. **متعدلش أي ملف مش مذكور في التاسك** إلا لو اختبار قديم وقع بسببك — ساعتها صلّح الاختبار واكتب في القسم الأخير إنك عملت كده وليه.
7. **ممنوع `tinker` أو سكربتات تحقق.** الدليل الوحيد المقبول اختبارات Pest.

### قواعد المشروع اللي هتلمسها هنا

- **ممنوع `float` خالص.** المبالغ `bigInteger` بالقروش (×100) عبر `MoneyCast`. الكميات ×1000 عبر `QuantityCast`.
- **`CashboxService` هو الكاتب الوحيد** لجدول `cashbox_transactions`. ممنوع تنشئ `CashboxTransaction` يدوي.
- **أي عملية بتلمس أكتر من جدول = `DB::transaction()` واحدة** + إعادة جلب الموديل بـ`lockForUpdate()` من جوه الترانزاكشن.
- **أي `toScaledInt()` جوه `try/catch`** من أول سطر، وكل حقل رقمي له `try/catch` منفصل برسالته العربية.
- **كل نص واجهة عربي.** الألوان من `resources/css/app.css` بس — **ممنوع hex في أي Blade**.
- **استخدم الـcomponents الموجودة** (`x-money`, `x-quantity`, `x-data-table`, `x-field`, `x-delete-button`, `x-quick-add`, `x-quick-field`) بدل تكرار markup.

**كلها داتا تجريبية.** أي backfill أو تحويل بيانات مش محتاج حرص خاص، ومسموح تمسحها لو ده أنضف.

# التاسك 3 — سجل العمليات (Activity Log)

**الهدف:** **كل** عملية إضافة أو تعديل أو حذف يعملها المستخدم على أي بيانات في السيستم تتسجل تلقائيًا، بإيه اللي اتغيّر وإمتى.

**القرار المعماري:** **نظام واحد عام**، مش سجل لكل كيان. بيشتغل على مستوى الموديل (Eloquent events) فبيغطي أي كود موجود أو جاي من غير ما حد يفتكر يستدعيه.

### 3.1 قاعدة البيانات

- [x] **3.1** Migration `create_activity_logs_table`:
  ```php
  Schema::create('activity_logs', function (Blueprint $table) {
      $table->id();
      $table->foreignId('user_id')->nullable()->constrained()->nullOnDelete();
      $table->string('subject_type');
      $table->unsignedBigInteger('subject_id');
      $table->string('subject_label')->nullable(); // وصف نصي للكيان وقت العملية (عشان يفضل مقروء بعد الحذف)
      $table->string('event');                     // created | updated | deleted
      $table->json('changes')->nullable();         // {"field": {"old": "...", "new": "..."}}
      $table->timestamp('created_at')->nullable();

      $table->index(['subject_type', 'subject_id']);
      $table->index('created_at');
      $table->index('event');
      $table->index('user_id');
  });
  ```
  **ملاحظة:** الجدول ده `created_at` بس بدون `updated_at` — السجل مبيتعدلش أبدًا.

### 3.2 المنطق

- [x] **3.2** `app/Models/ActivityLog.php`
  - `#[Fillable([...])]`
  - casts: `'changes' => 'array'`, `'created_at' => 'datetime'`
  - `public $timestamps = false;` مع ضبط `created_at` يدوي عند الإنشاء
  - علاقة `user(): BelongsTo`
  - **الموديل ده مش بياخد الـtrait** (ممنوع يسجّل نفسه)

- [x] **3.3** `app/Services/ActivityLogService.php` — `record(Model $model, string $event): void`
  - `created` → `changes = null`
  - `updated` → لكل مفتاح في `$model->getChanges()` **ماعدا `updated_at`**: `['old' => format($model->getOriginal($key)), 'new' => format($model->getAttributes()[$key])]`. **لو مفيش تغييرات بعد الاستبعاد، متسجلش حاجة أصلاً.**
  - `deleted` → `changes = null`
  - `user_id = auth()->id()` (ممكن `null` في console/tests — ده طبيعي)
  - `subject_label` = نتيجة `activityLabel()` على الموديل (تحت)

  **دالة `format()` الخاصة — تحويل القيمة الخام لنص مقروء:**
  - لو الـcast بتاع العمود `MoneyCast::class` → `MoneyCast::toDisplayString((int) $raw)` *(الدالة دي موجودة، شوف `PaymentController::store`)*
  - لو `QuantityCast::class` → نفس المنطق بـ`QuantityCast`. **لو الدالة مش موجودة على `QuantityCast`، ضيفها بنفس شكل اللي في `MoneyCast` بالظبط — ومتغيّرش أي سلوك قايم.**
  - لو الـcast enum → `$enum::from($raw)->label()`
  - `null` → `'—'`، `bool` → `'نعم'` / `'لا'`
  - أي حاجة تانية → `(string) $raw`

# التاسك 4 — أنواع الخامات

**الهدف:** الخامة ليها نوع: **خامة** أو **اكسسوار**. الأسماء تتعدّل من الإعدادات. إضافة أنواع جديدة **مش متاحة للمستخدم** دلوقتي، بس البنية تسمح بيها بعدين.

**القرار:** **جدول lookup مستقل**، مش enum. ده قرار صريح من المستخدم عشان إضافة أنواع بعدين تبقى سهلة.

> ملاحظة للسياق: جدول `categories` اتشال قبل كده (`drop_categories_from_materials`). ده **مش رجوع** عنه — ده جدول مختلف بغرض مختلف ومحدود بنوعين.
